1. Khẳng Định Vai Trò Cá Nhân & Bối Cảnh Dự Án

Tuyên bố quyền tác giả: Website potty.vn là dự án thương mại điện tử thực tế do Khương Tuấn Anh trực tiếp đảm nhiệm toàn diện vai trò Solo Creator & Web Developer. Toàn bộ các công đoạn từ thuê tên miền, máy chủ, dựng hệ thống WordPress, viết code Child Theme, tùy biến giao diện CSS, chụp và chỉnh sửa ảnh sản phẩm, cho đến tối ưu luồng thanh toán và SEO đều do cá nhân tự tay thực hiện độc lập.

Khác với việc sử dụng các nền tảng đóng gói sẵn kéo thả đơn giản, dự án Potty.vn được xây dựng trên nền tảng mã nguồn mở độc lập (Self-hosted WordPress). Điều này đòi hỏi kiến thức sâu sắc về kiến trúc website, hệ quản trị cơ sở dữ liệu, khả năng viết code CSS/PHP tùy biến và tích hợp các API thanh toán bên thứ ba để đảm bảo trải nghiệm người dùng liền mạch và tin cậy nhất.

2. Các Nền Tảng, Công Nghệ & Code Sử Dụng Để Tạo Nên Website

Dưới đây là các thành phần công nghệ cốt lõi được kết hợp chặt chẽ trong hệ thống của Potty.vn:

WordPress Core & Kỹ Thuật Dựng Child Theme

Sử dụng WordPress phiên bản 6.x làm hệ thống quản trị nội dung (CMS). Thay vì sửa trực tiếp vào theme gốc (gây nguy cơ mất dữ liệu khi cập nhật), tôi đã tự tay xây dựng Child Theme riêng biệt: potty-child-theme-v3 để quản lý toàn bộ các đoạn code tùy biến functions, style và asset.

  • Quản trị máy chủ, cấu hình tên miền tại Registrar, trỏ DNS và cài đặt chứng chỉ bảo mật SSL (Let's Encrypt).
  • Phân bổ cấu trúc cây thư mục sạch, tối ưu bộ nhớ đệm cache và phân quyền tài khoản bảo mật.
Custom Code CSS & Tối Ưu Hiển Thị Tiếng Việt

Rất nhiều theme WordPress quốc tế bị lỗi font khi hiển thị tiếng Việt (dấu bị lệch hoặc vỡ khoảng cách). Tôi đã viết các đoạn CSS chuyên biệt để chuẩn hóa tính năng typography và trải nghiệm di động:

/* Potty: Tối ưu typography tiếng Việt liền nét & tương phản nút CTA */
html {
  -webkit-font-smoothing: antialiased;
  font-feature-settings: "kern" 1, "liga" 1;
}
h1, h2, h3, h4 {
  font-family: Cambria, "Times New Roman", serif;
}
a.button.button-primary {
  background-color: #183421 !important;
  border-color: #244b2f;
  color: #ffffff !important;
}

Đồng thời viết media queries xử lý riêng cho màn hình nhỏ (<768px và <360px) để đảm bảo thanh tìm kiếm thông minh, icon giỏ hàng và form checkout không bị tràn ngang layout.

Hệ Thống Bán Hàng E-Commerce WooCommerce

Thiết lập kiến trúc danh mục sản phẩm logic và trực quan:

  • Phân nhóm sản phẩm: Tinh dầu thiên nhiên nguyên chất (Hương Lài, Oải Hương, Cam Ngọt, Sả Chanh, Quế...), Tinh dầu treo xe ô tô, Máy khuếch tán phun sương và Combo quà tặng.
  • Biến thể linh hoạt (Variable Products): Quản lý dung tích lọ 10ml, 30ml, tự động cập nhật giá tiền tương ứng.
  • Tối ưu giỏ hàng & Checkout: Thu gọn các trường nhập thông tin không cần thiết để giảm tỷ lệ bỏ giỏ hàng (Cart Abandonment).
Tích Hợp Cổng Thanh Toán Tự Động 9Pay VietQR

Khách hàng mua sắm online tại Việt Nam rất chuộng chuyển khoản quét mã VietQR. Tôi đã cài đặt và cấu hình cổng thanh toán trung gian 9Pay Gateway:

  • Mỗi đơn hàng tạo ra một mã VietQR động với đúng số tiền và cú pháp mã đơn hàng.
  • Tích hợp Webhook đồng bộ: Khi khách hàng chuyển khoản thành công tại ngân hàng, hệ thống 9Pay gửi tín hiệu callback tức thì để WooCommerce tự động chuyển đơn sang trạng thái Đang xử lý (Processing) mà không cần nhân viên kiểm tra thủ công.
Thiết Kế UI/UX & Bộ Nhận Diện Thương Hiệu (Eco-Aesthetic)

Xây dựng phong cách thị giác mang đậm bản sắc thiên nhiên và thư giãn:

  • Bảng màu: Phối hợp màu xanh rừng lá đậm (#183421, #244b2f) tạo cảm giác thảo mộc nguyên bản, cùng tông nền kem ngà ấm (#fbf8f1, #edf2e9) tạo sự dịu mắt và cao cấp.
  • Thanh bảo chứng niềm tin (Trust Strip): Nêu bật 5 cam kết rõ ràng: Thông tin rõ ràng · Dùng đúng hướng dẫn · Tiêu chí rà soát · Bao bì bảo quản · Tư vấn tận tâm.
  • Chính sách minh bạch: Miễn phí vận chuyển từ 300K, đổi trả trong 7 ngày nếu không ưng ý mùi hương.
Tối Ưu Hóa Kỹ Thuật SEO (Rank Math & Schema JSON-LD)

Cấu hình công cụ Rank Math SEO để tối ưu cấu trúc dữ liệu máy tìm kiếm:

  • Khai báo Schema Markup chuẩn: Organization, Store, WebSite và Product kèm thông tin giá tiền, tồn kho.
  • Tối ưu thẻ OpenGraph preview, Twitter card khi chia sẻ link lên Facebook, Zalo hiển thị banner và tiêu đề bắt mắt.
  • Chuyển đổi toàn bộ hình ảnh sang định dạng WebP nén không giảm chất lượng, tích hợp lazy-load để tăng tốc độ tải trang.
